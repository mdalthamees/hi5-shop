# HI-5 கருப்பு கடை

Responsive boutique storefront for HI-5 கருப்பு கடை, built with React and Vite.

## Run locally

From the `hi5-karuppu-kadai` directory:

```bash
npm ci
npm run dev
```

Open the local URL printed by Vite (normally http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Deploy to Render

The root-level `render.yaml` defines a Render static site. In Render, create a
new Blueprint and connect this GitHub repository. Render installs dependencies
from the app lockfile, runs the production build, and serves the `dist` output.

See [the app README](hi5-karuppu-kadai/README.md) for project structure and
product-editing guidance.
